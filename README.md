# SwiftSlate Writer AI update

This repository contains the source/decompiler patch for the requested SwiftSlate v1.0.82 changes.

Requested:
- Writer AI provider
- https://api.writer.com/v1
- palmyra-x6 and palmyra-x5
- trigger prefixes of 1 or 2 characters
- preserve Gemini, Groq and Custom

Important: the supplied runtime has no Android SDK/aapt/apktool/smali assembler, so a rebuilt/signed APK is not claimed from this environment. The patch is provided for the original build/rebuild pipeline.
